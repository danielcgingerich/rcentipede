# RCentipede

Implementation of the CENTIPEDE algorithm (Pique-Regi et al) in R statistical programming language

The original work by the original authors can be found [here](https://pmc.ncbi.nlm.nih.gov/articles/PMC3044858/)

See [DESCRIPTION.pdf](https://github.com/danielcgingerich/rcentipede/blob/main/DESCRIPTION.pdf) for a general overview, and the paper for further details
